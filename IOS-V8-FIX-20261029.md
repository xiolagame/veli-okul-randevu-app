# Codemagic Node/V8 Wasm çökmesi

Hedef dal: feature/ios-codemagic-final-20261029. Başlangıç f2ad60a02dc428435d6848821f4cd704b188e7ed.

## Teşhis ve kapsam

Kullanıcının verdiği fatal CHECK ve UnregisterWasmAllocation/FreeCode stack'i native V8 hatasıdır; uygulama assertion hatası değildir. Yerel Windows çalıştırmasında özgün çökme yeniden üretilemedi. Node projesinde benzer Wasm kod GC/free yolu için açık hata kaydı bulunuyor: https://github.com/nodejs/node/issues/66366. Aynı kök neden kesin kanıtlanmış değildir; stack ile uyumlu çalışma varsayımıdır.

Runner zaten spawnSync döngüsüyle sıralı ve her veritabanı testi ayrı child process ve PGlite klasöründe çalışır. Süreçler arası paralellik veya ortak database dosyası yok. V8'in süreç içindeki Wasm kod GC davranışı bu izolasyondan bağımsızdır.

## Dar düzeltme

- Yalnız 9 PGlite test child process'ine --no-wasm-code-gc eklendi. Test süreci sona erdiğinde işletim sistemi kod belleğini geri alır. JS garbage collector, assertion'lar ve bütün testler aktif.
- Sinyal, Node/V8 sürümü ve runtimeArgs sonuç JSON'unda kaydediliyor; sinyal, spawn error veya sıfır olmayan exit kodu FAIL. Retry veya sahte PASS yok.
- 16 MiB çıktı sınırı, uzun yerel migration tanılarının varsayılan spawnSync buffer'ını aşmasını önler; timeout 240 saniye korunuyor.
- Üç YAML workflow zaten Node 24.17.0 kullanıyordu; .node-version da 24.17.0 olarak sabitlendi. Sürüm düşürülmedi veya V8 bug'ı düzeltilmiş sürüm iddiasında bulunulmadı.
- Üç workflow sürüm çıktısına V8/platform/architecture eklendi. ios-ci-check ve ios-signed-ipa aynı düzeltilmiş runner'ı kullanıyor.
- test-account-deletion.ts değiştirilmedi.

Codemagic Xcode 26.6 imaj belgeleri Node 24.17.0 / npm 11.13.0 gösteriyor: https://docs.codemagic.io/specs-macos/xcode-26-6/. Npm YAML'da ayrıca sabitlenmemiştir; başarısız build'in gerçek npm logu bu görevde verilmedi. Yerel npm 11.19.1; testler resmi SHA256 kontrolü yapılan Node 24.17.0 Windows executable ile çalıştırıldı (V8 13.6.233.17-node.49).
